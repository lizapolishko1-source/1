# Проєкт IoT-системи: «Розумна теплиця»

## 1. Загальний опис проєкту
Система призначена для автоматизованого моніторингу та управління мікрокліматом у промисловій теплиці площею 200 м². Головна мета — оптимізація умов вирощування культур, мінімізація витрат води та енергоресурсів, а також забезпечення автономності системи у разі втрати зв'язку з хмарним сервером.

---

## 2. Архітектура IoT-системи (Mermaid-діаграма)

Архітектура побудована за стандартною 4-рівневою моделью IoT (ITU-T Y.2060):

```mermaid
graph TD
    subgraph L1 [Рівень сприйняття - Perception Layer]
        D1[Датчик температури і вологості повітря BME280]
        D2[Датчик вологості та температури ґрунту]
        D3[Датчик освітленості Lux-метр]
        D4[Датчик рівня CO2]
        A1[Виконавчі реле поливу]
        A2[Приводи вентиляції та форточок]
        A3[Фітолампи досвітлення]
        A4[Система опалення]
    end

    subgraph L2 [Мережевий рівень - Network Layer]
        N1[Локальна мережа: інтерфейс RS-485 / Modbus RTU]
        N2[Шлюз IoT Edge Gateway з підтримкою Wi-Fi / 4G]
    end

    subgraph L3 [Рівень обробки - Processing & Storage Layer]
        E1[Локальний Edge-контролер / Node-RED / локальна БД SQLite]
        C1[Хмарна платформа AWS IoT / сервер баз даних Time-series DB]
    end

    subgraph L4 [Рівень застосунків - Application Layer]
        W1[Вебдодаток та Dashboard агронома]
        M1[Мобільний застосунок для сповіщень Push/Telegram]
    end

    D1 --> N1
    D2 --> N1
    D3 --> N1
    D4 --> N1
    N1 --> N2
    
    A1 -.-> N1
    A2 -.-> N1
    A3 -.-> N1
    A4 -.-> N1

    N2 --> E1
    E1 --> C1
    C1 --> W1
    C1 --> M1
